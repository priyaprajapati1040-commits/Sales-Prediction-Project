\# Sales Prediction Using Python



\## Project Overview



This project predicts future sales using advertising expenditure data from TV, Radio, and Newspaper marketing channels using Machine Learning.



\## Technologies Used



\* Python

\* Pandas

\* Matplotlib

\* Scikit-Learn



\## Machine Learning Algorithm



\* Linear Regression



\## Dataset



The dataset contains:



\* TV Advertising Budget

\* Radio Advertising Budget

\* Newspaper Advertising Budget

\* Sales



\## Results



\* R² Score: 0.8994

\* Mean Absolute Error (MAE): 1.4608

\* Predicted Sales: 19.63



\## Features



\* Data Cleaning

\* Feature Selection

\* Model Training

\* Sales Forecasting

\* Data Visualization
